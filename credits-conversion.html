Credits conversion

Celonis consumption across AI, Compute, and Storage is unified into a single Credits balance. Each lane meters usage in its own unit (tokens, CPU-hours, machine-hours, terabytes) and has its own Credit rate, which can vary further by sub-type. Expand a lane below to see its rates.
AI Tokens

AI token usage is priced per model and per token type (input, output, cache read and cache write). Rates are in Credits per 1 million tokens.

Compute

Compute usage is grouped into three buckets. Analytics engines and Data processing are metered per CPU-hour. ML Workbench is metered per hour of machine time, with a rate for each machine type.
